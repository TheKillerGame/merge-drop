# Merge Drop

A drop-and-merge phone game. Drag along the top and let go to drop a fruit
into the jar. Two of the same fruit touching merge into the next one up the
chain. If fruit sits above the red line for 2 seconds, the jar is full and the
run is over.

By **RisingForce**.

## Play

Open `index.html` in any browser, on a phone or a computer. It's a single file
with no install, no server and no internet needed (the fonts are embedded and
the sounds are made in code). Drag and release with a finger or the mouse, or
use the arrow keys and Space.

## Features

- The chain: cherry, strawberry, grape, orange, persimmon, apple, pear, peach,
  pineapple, melon, watermelon. Two watermelons pop for +100.
- Real physics: fruit rolls, tumbles and settles
- Tools every run: 1 **shake** (jostles the whole jar) and 1 **pop** (tap a
  fruit to remove it)
- 7 jars, each with its own shape, emblem and power, won by making a bigger
  fruit for the first time:
  - **classic**: no tricks
  - **wide** (first persimmon): 13% wider
  - **lucky** (first pear): see the next two fruit
  - **tall** (first peach): taller, a bit narrower
  - **magnet** (first pineapple): matching fruit close by pull together
  - **toolbox** (first melon): +1 shake and +1 pop every run
  - **golden** (first watermelon): every merge scores 1.5x
- Coins: 1 per 50 points, plus 15 missions
- Store: extra shakes and pops, and background patterns
